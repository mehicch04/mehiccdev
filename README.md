# mehiccdev.com

Website of **mehiccdev**, a web and digital studio from Mostar, Bosnia and Herzegovina. It presents our services, pricing and portfolio, and showcases the car rental booking system we build for clients.

**Live:** [mehiccdev.com](https://mehiccdev.com)

![mehiccdev.com](https://mehiccdev.com/opengraph-image)

## Tech stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Zod
- Resend
- Vercel
